# PMの取り組み（Daiche-0624）

## 要件定義・スコープ管理
- バイト先へのヒアリングシートを作成し、課題を「業務フロー・痛み・理想」の3段階で整理
- メンバーから多数の機能提案が出た際、「ないと成立しないか」という判断軸でMVPを3機能に絞り込み
- GitHub Issuesで8つのタスクを作成し、担当・優先順位・完了条件を明確化

## チーム調整
- キックオフミーティングの資料を自作し進行
- 完成定義のズレが生じた際は即座に謝罪・再整理
- 技術的判断はエンジニアに委ね、PMは進捗管理に集中

## 苦労した点
- 初学者チームのため、技術的に何が可能かを把握しながらスコープを調整するのが難しかった
- メンバーのモチベーションを維持しながら機能を削る判断が特に難しかった

## AIの活用について
- Claude AIをPM業務の補助として活用
- 機能の取捨選択・チーム調整・意思決定はすべて自分で実施
- AIはあくまで作業効率化ツールとして使用
