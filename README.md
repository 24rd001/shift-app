# シフト管理アプリ

## 概要
アルバイト先のシフト管理における課題を解決するWebアプリです。
店長とスタッフが、シフト希望提出・確認・交代申請を一元管理できます。

## 解決したい課題
- LINEや紙でのシフト連絡による情報の埋没
- 店長のシフト集計作業の負担
- スタッフ同士のシフト交代の属人化

## 主な機能
- ログイン・新規登録（スタッフ／管理者）
- シフト一覧表示
- シフト希望提出
- シフト交代申請（承認フロー付き）
- 管理者によるシフト作成・確定

## 使用技術
| カテゴリ | 技術 |
|------|------|
| フロントエンド | HTML / CSS / JavaScript |
| バックエンド | TypeScript / AWS Lambda |
| データベース | AWS DynamoDB |
| 認証 | AWS Cognito |
| インフラ | AWS SAM / API Gateway |
| バージョン管理 | GitHub |
